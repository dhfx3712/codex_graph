# 部署摘要卡：serve_graph.py 静态服务

元信息：
  路径: serve_graph.py
  类型: Python 标准库 http.server.ThreadingHTTPServer（静态文件服务，无 API/无业务路由）
  入口: .venv/bin/python serve_graph.py --host 0.0.0.0 --port 6134 [--public-host <公网IP或域名>]
  技术栈: 仅标准库（argparse / http.server / functools）

结构（目录托管）：
  WEB_DIR = 脚本所在目录 / web（托管 index.html + graph_data.json）
  自定义处理器: GraphHandler(http.server.SimpleHTTPRequestHandler)
    - __init__ 绑定 directory=WEB_DIR
    - parse_request() → 拒绝 TLS/HTTPS 握手包（首字节 \x16\x03）→ 关连接
    - end_headers() → 加 Cache-Control: no-store, must-revalidate
    - log_message() → 前缀 [graph]

数据契约：
  无 API；仅 GET 静态资源（/index.html、/graph_data.json 等）
  前端通过 fetch('graph_data.json') 同源取数

状态 state：
  无持久状态；进程常驻 serve_forever()

函数地图：
  - parse_args() → --host(默认0.0.0.0)/--port(默认6134)/--public-host(默认"")
  - main() → 校验 WEB_DIR 存在 → 设 GraphHandler.public_host → ThreadingHTTPServer → serve_forever

调用链/交互：
  浏览器 → http://<host>:6134/ → index.html → fetch graph_data.json（同源）→ Canvas 渲染

关键逻辑：
  - 多线程 ThreadingHTTPServer；每请求一线程
  - 显式拒绝 HTTPS（避免混淆）：检测到 TLS 记录直接关闭连接并提示用 http://
  - 静态无鉴权、无 CORS 限制（同源即可）

常见修改点：
  - 改端口 → --port / 默认 6134
  - 改绑定地址 → --host
  - 改托管目录 → WEB_DIR 常量（当前 web/）
  - 加基础鉴权/HTTPS → 需改 GraphHandler（当前不支持）

约束与坑：
  - ★ 必须在**项目根目录**运行（WEB_DIR 相对 __file__ 父目录/web，依赖 CWD/路径）
  - 仅静态托管：业务逻辑（检索/构建）在别的脚本，前端不含检索接口；查询走 query_chunk_faiss.py CLI
  - WEB_DIR 不存在 → 直接 return 2（启动失败）
  - graph_data.json 缺失时页面 hint 显示"加载失败"（不影响服务进程）
  - 无进程守护（systemd/supervisor 需自行配）；停服 Ctrl+C
  - 公网暴露 0.0.0.0 无鉴权，注意防火墙/安全组
