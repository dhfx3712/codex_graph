# 后端摘要卡：处理流水线脚本集

元信息：
  路径: 仓库根（*.py）
  类型: Python 3 CLI 批处理脚本（无 API Server、无 Web 框架）
  入口:
    - 摘要切片: .venv/bin/python summarize_pipeline.py
    - 建索引:   .venv/bin/python build_chunk_faiss.py [--max-rows N]
    - 语义查询: .venv/bin/python query_chunk_faiss.py "问题" [--top-k N]
    - 建图谱:   .venv/bin/python build_graph.py [--max-rows N] [--max-evidence N] [--seed N]
    - 统计:     .venv/bin/python count_graph_stats.py [--limit N] [--json]
    - 清理:     .venv/bin/python dedupe_undo_articles.py [--dry-run]
  技术栈: requests、sentence-transformers、faiss-cpu、numpy、networkx（build_graph）

结构（模块/脚本树）：
  - summarize_pipeline.py  → 文章切片 + LLM 摘要/图谱（写入 CSV）
  - build_chunk_faiss.py   → CSV→FAISS+SQLite
  - query_chunk_faiss.py   → 查询（读 FAISS+SQLite）
  - build_graph.py         → CSV→web/graph_data.json（NetworkX 图谱）
  - count_graph_stats.py   → 统计 chunks.csv
  - dedupe_undo_articles.py→ 清理 undo 已处理文件

数据契约（summary_json 形状，LLM 输出后落 CSV）：
  文章级: { human_summary, core_theme, key_points:[], entities:[{name,type,aliases[],evidence}], relationships:[{source,target,relation,evidence}] }
  切片级: { human_summary, core_argument, entities:[...], relationships:[...], context_to_next, boundary_incomplete }
  查询返回: { query, hits:[{faiss_id, score, id, article_id, chunk_index, content, summary, summary_json(dict)}] }

函数地图：
  【summarize_pipeline.py】
  - load_env_file() → 读 ENV_FILE 注入 os.environ（缺失则跳过）
  - ensure_directories() / pending_markdown_files() → 建目录 / 列 undo/*.md
  - load_existing_ids() / ensure_header() / append_unique_rows() → CSV 幂等读写（按 id 去重）
  - move_to_done(md_path) → undo→do 归档（重名加时间戳）
  - clean_markdown() / split_sentences() / split_long_sentence() / chunk_article() → 清洗+切片（目标 700 / 最大 1000 字，过短合并前块）
  - call_llm(prompt,max_tokens,temperature,json_mode) → 调 Volc/Ark chat/completions
  - parse_json_response() → 从文本抠合法 JSON（处理 ``` 围栏/嵌套括号）
  - validate_graph_relations() → 校验 relation ∈ ALLOWED_RELATIONS
  - call_llm_json(...) → 截断/非法 JSON 重试 + 降实体兜底（build_prompt_with_reduced_entities）
  - adjacent_contexts() → 前后切片 120 字衔接上下文
  - generate_article_rows(md_path) → 单文件：清→切→LLM(文章+每片)→产出 article_row + chunk_rows
  - main() → ThreadPoolExecutor(max_workers) 并发处理多个 md
  【build_chunk_faiss.py】
  - resolve_model_path() → 定位本地模型快照目录
  - load_summary_text() → 取 summary_json.human_summary + "\n" + core_argument 作 embedding 文本（无则 None→跳过该 chunk）
  - make_row_hash() → 行级 SHA256 去重
  - read_chunk_records(max_rows) → 读 chunks.csv，统计 skipped/duplicate
  - build_index(vectors) → IndexIDMap2(IndexFlatIP(384))
  - write_sqlite_metadata() → 写 chunk_vectors/chunk_texts/build_info 三表
  - replace_outputs_atomically() → 原子替换（先备 DB 再替换，失败回滚）
  - main() → 设离线环境变量→加载模型→encode→建索引→写临时文件→原子替换
  【query_chunk_faiss.py】
  - load_model() / search(query,top_k) → 同模型编码 query→FAISS search→join SQLite→返回 hits
  - main() → CLI 包装 search 打印 JSON
  【build_graph.py】
  - UnionFind(类) → 按 name+aliases 合并实体节点
  - normalize_key() / simplify_type()（TYPE_RULES 归并大类）/ safe_json()
  - read_chunks() → 解析 chunks.csv summary_json 抽 entities/relationships
  - build_nodes_and_edges() → 建图+度/加权度/size 计算
  - compute_community_layout() → Louvain 分簇 + 簇内 spring（超大连环改圆环）预计算 x/y
  - main() → 写 web/graph_data.json（meta/nodes/edges）
  【count_graph_stats.py】main() → 统计实体/关系数量与 Top20、节点量估算，可选 --json
  【dedupe_undo_articles.py】main() → undo 中已在 do 的文件删除（--dry-run 仅提示）

调用链/交互：
  undo/*.md → summarize_pipeline → results/{articles,chunks}.csv → (build_chunk_faiss → {chunks.faiss, chunks_meta.sqlite3} → query_chunk_faiss) 与 (build_graph → web/graph_data.json → web/index.html)
  call_llm 为 summarize_pipeline 单点外部依赖；其余脚本本地计算，无跨脚本调用（仅 query/build 复用 build_chunk_faiss 的常量）

关键逻辑：
  - 并发：summarize_pipeline 用 ThreadPoolExecutor，线程数=SUMMARIZE_PIPELINE_WORKERS(默认4)
  - FAISS 每次**全量重建**（非增量）；向量归一化 + IndexFlatIP 等价于余弦
  - 同一 id：内容一致忽略；内容不同忽略新行并 WARNING（不抛错、不覆盖）
  - 切片粒度：CHUNK_TARGET=700，CHUNK_MAX=1000（单超长句按标点拆分）
  - 图谱布局坐标由后端预计算，前端只读

常见修改点：
  - 换 LLM 模型/密钥 → summarize_pipeline.py 的 ENV_FILE、VOLC_BASE_URL/MODEL_NAME、ARK_API_KEY
  - 改切片粒度 → summarize_pipeline.py 的 CHUNK_TARGET / CHUNK_MAX
  - 改允许的关系类型 → summarize_pipeline.py 的 ALLOWED_RELATIONS（含中英文映射约束）
  - 改 embedding 文本来源 → build_chunk_faiss.py 的 TEXT_FIELDS
  - 改向量维度/模型 → build_chunk_faiss.py 的 DIMENSION、MODEL_REPO_DIR（须与 query 一致）
  - 改图谱节点类型归并 → build_graph.py 的 TYPE_RULES
  - 改前端图谱数据 → build_graph.py 输出字段（web/graph_data.json）

约束与坑：
  - ENV_FILE = /home/ubuntu/codex_graphrag/.ollmam_env，与 README 写的 /home/ubuntu/codex_english/.env **路径不一致**（坑：照 README 配不生效，必须放 .ollmam_env）

  - query_chunk_faiss.search() 每次重新加载模型+索引（低频单次用，高频需自行缓存复用）
  - 中文标点切句；clean_markdown 会去代码块/加粗/链接/标题，影响切片纯净度
