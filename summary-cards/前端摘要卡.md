# 前端摘要卡：web/index.html

元信息：
  路径: web/index.html
  类型: 纯 vanilla JS (ES6 IIFE) + Canvas 2D 渲染；无框架、无 CDN 依赖（离线可用）
  入口: 由 serve_graph.py 静态托管后浏览器访问 http://<host>:6134/
  技术栈: HTML5 Canvas 2D、fetch、requestAnimationFrame、Map/Set

结构（DOM id）：
  - 布局: #app > #toolbar + #workspace(#canvasWrap>#canvas, #hint, #legend) + #detail
  - 搜索/筛选: #searchInput、#searchResults、#coreCount、#coreToggle、#nodeTypeFilter、#relationFilter
  - 视图控制: #deselectButton、#resetViewButton、#stats
  - 浮层: #tooltip

数据契约：
  输入（init() 中 fetch('graph_data.json', {cache:'no-store'})）形状：
  - meta: { type_colors:{type:color}, type_distribution:{}, relation_distribution:{}, node_count, edge_count, layout }
  - nodes[]: { id, name, type, type_simple, aliases[], evidence:[{text, chunk_id, article_id, chunk_index}], mentions, degree, in_degree, out_degree, weighted_degree, size, x, y }
  - edges[]: { id("source__target"), source, target, weight, relations:[{relation, count, evidence:[{text, chunk_id, article_id, chunk_index}]}] }
  输出（无）：纯展示，不做任何写回。

状态 state：
  init() 内闭包 state 对象，关键可变字段：
  - data/nodes/edges/byId/edgeById/adjacency/nodeEdges（图数据索引）
  - coreIds（按 degree 降序的全部节点 id）
  - selectedNodeId / selectedEdgeId / hoverNodeId / hoverEdgeId
  - coreMode(bool) / coreCount(默认200) / nodeType / relationType
  - view:{x,y,scale}（画布平移缩放）
  - expandedRoots:Set（双击展开/手动加入核心集合的节点）

函数地图：
  - init() → 异步引导：fetch JSON→建 Map/邻接表→populateFilters→renderLegend→rebuildVisible→resize→fitVisible
  - buildSearchIndex() / ensureSearchIndex() / updateSearchResults() → 搜索（name/type/alias 匹配，按 degree 排序）
  - computeVisibleNodeSet() / getCoreSet() / rebuildVisible() / updateStats() → 可见性过滤（核心视图+类型筛选）
  - selectNode(id) / selectEdge(id) / clearSelection() / expandNode(id) / toggleCoreMode() → 选中状态变更
  - renderDetail() → 右侧面板渲染节点（badges/度/别名/evidence）或边（relations/evidence）
  - renderLegend() / populateFilters() → 图例与下拉填充
  - scheduleDraw() / draw() / drawArrow() → 渲染主循环（rAF），含高亮边箭头
  - fitVisible() / centerOnNode() / zoomAt() / resize() → 视口变换与高 DPR 适配
  - pickNode() / pickEdge() / distanceToSegment() → 命中检测
  - showTooltip() / hideTooltip() / escapeHtml() → 浮层与 XSS 防护

调用链/交互：
  - init → fetch graph_data.json → 建索引 → 渲染
  - 画布 mousedown：点节点=选中+可拖拽；点边=选中；空白=平移（松手且未移动=清除选中）
  - mousemove：悬浮高亮+tooltip；拖拽节点实时改 node.x/y
  - dblclick 节点 → expandNode（加入 expandedRoots + 切核心视图）
  - wheel → zoomAt（以光标为中心缩放，scale∈[0.01,3]）
  - searchInput input → updateSearchResults；结果点击 → selectNode+居中
  - 详情面板按钮 data-action: clear/center/expand/focus-node/neighbors

关键逻辑：
  - 布局坐标(x,y)由后端 build_graph.py 预计算（Louvain+spring），前端只读不重算
  - 核心视图：state.coreIds 前 coreCount 个 + expandedRoots 及其邻居
  - 标签显隐阈值在 draw() 内：selected/hover 恒显；可见≤220 全显；scale>0.35 且 degree≥8；scale>0.18 且 degree≥25；核心模式 degree≥4
  - 边方向：DiGraph，绘制箭头指向 target；选中时出边蓝#4ea1ff、入边橙#f4a261

常见修改点：
  - 改节点配色 → type_colors（meta，后端 build_graph.py 写）/ CSS :root --accent
  - 改默认核心点数 → #coreCount 默认 value=200 与 state.coreCount
  - 改标签显示密度 → draw() 内 showLabel 各条件分支
  - 改画布交互手感 → mousedown/mousemove/wheel 监听与 zoomAt 的 factor
  - 改详情面板字段 → renderDetail()
  - 改 Evidence 溯源 → build_graph.py 的 make_evidence() / read_chunks() 增加 article_id+chunk_index；web/index.html 的 renderEvidence()
  - 改搜索/筛选维度 → buildSearchIndex 的 haystack 字段 + populateFilters

约束与坑：
  - 必须经 HTTP 同源加载（serve_graph.py 托管），不能用 file:// 直接打开（fetch 会失败，hint 显示"加载失败"）
  - graph_data.json 必须存在且由 build_graph.py 先生成；结构缺字段会渲染空白/报错
  - 无任何第三方库，离线可用；但若要加库需自行引入（无打包器）
  - escapeHtml 已做注入防护，新增 innerHTML 拼接务必走 escapeHtml
  - 节点 id 含 `#` 后缀（同名去重时加序号），点击定位依赖 byId Map，勿改 id 生成规则
