# 外部服务卡：Volc / Ark LLM API

元信息：
  服务: 火山方舟（Volcengine Ark）OpenAI 兼容 chat/completions
  调用点（唯一）: summarize_pipeline.py: call_llm()
  鉴权: HTTP Bearer，请求头 Authorization: Bearer {ARK_API_KEY}
  技术栈: requests（同步，timeout=120）
  触发: summarize_pipeline 每篇文章 1 次 + 每个切片 1 次调用

数据契约：
  请求体（POST {VOLC_BASE_URL}/chat/completions）:
    { model, messages:[{role:"user",content:prompt}], temperature, max_tokens,
      response_format?: {"type":"json_object"} }  # json_mode=True 时
  响应:
    choices[0].message.content（字符串 JSON）；choices[0].finish_reason（"length"=截断）
  模型默认: MODEL_NAME = doubao-seed-2.0-lite
  端点默认: VOLC_BASE_URL = https://ark.cn-beijing.volces.com/api/coding/v3

关键结构（prompt 模板）：
  - ARTICLE_SUMMARY_PROMPT → 输出 {human_summary, core_theme, key_points, entities, relationships}
  - CHUNK_SUMMARY_PROMPT → 输出 {human_summary, core_argument, entities, relationships, context_to_next, boundary_incomplete}
  - 两者均约束 relation ∈ ALLOWED_RELATIONS（17 种中文关系）

函数地图：
  - call_llm(prompt,max_tokens,temperature,json_mode) → 发请求、校验空内容、检测截断
  - parse_json_response(content) → 抠合法 JSON（去 ``` 围栏、按括号深度匹配）
  - validate_graph_relations(data) → relation 白名单校验，非法抛 ValueError
  - call_llm_json(...) → 截断/非法时重试（SUMMARIZE_JSON_RETRIES 默认2）+ 降实体兜底
  - build_prompt_with_reduced_entities() → 把"8-15 实体"改成"6-12"做降级重试
  - load_env_file() → 读 ENV_FILE 取 ARK_API_KEY（缺失则 call_llm 抛 RuntimeError）

调用链/交互：
  generate_article_rows → call_llm_json → call_llm → Ark API → 解析/校验/重试

关键逻辑：
  - 并发调用受 ThreadPoolExecutor(max_workers=SUMMARIZE_PIPELINE_WORKERS) 限制，无显式限流
  - max_tokens: 文章 2500、切片 1200；截断抛 LLMTruncatedError 并翻倍重试（上限 SUMMARIZE_MAX_OUTPUT_TOKENS=8192）
  - JSON 非法/截断最多重试 max_retries 次，仍失败走 reduced-entities 兜底，再失败抛最后异常

常见修改点：
  - 换模型 → MODEL_NAME 环境变量（或 ENV_FILE）
  - 换接入点/区域 → VOLC_BASE_URL 环境变量
  - 改密钥 → ARK_API_KEY 环境变量 / ENV_FILE
  - 改并发数 → SUMMARIZE_PIPELINE_WORKERS
  - 改重试/输出上限 → SUMMARIZE_JSON_RETRIES / SUMMARIZE_MAX_OUTPUT_TOKENS
  - 改输出 schema → ARTICLE_SUMMARY_PROMPT / CHUNK_SUMMARY_PROMPT（须同步 ALLOWED_RELATIONS）

约束与坑：
  - ARK_API_KEY 缺失且无 ENV_FILE → call_llm 抛 RuntimeError（非静默）
  - 仅 summarize_pipeline 依赖外部 LLM；build/query/graph 全本地，断网可用（已设离线环境变量）
  - finish_reason=="length" 被显式识别为截断错误（普通空内容走 ValueError）
  - 无超时重试/退避；网络抖动 120s 直接抛异常，该文件落入 failed_files 保留在 undo
  - 模型回复若夹 ```json 围栏，parse_json_response 已处理；但仍要求"只输出 JSON"
