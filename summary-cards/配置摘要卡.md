# 配置摘要卡：环境变量 / 模型缓存 / 离线开关

元信息：
  路径: ENV_FILE（硬编码）、各脚本内 os.getenv、本地 HF 缓存目录
  类型: 文件级 .env + 进程环境变量 + 本地模型缓存
  入口: summarize_pipeline.load_env_file() 启动时加载；其余脚本读 os.getenv / 设离线变量

配置项：
  【ENV_FILE 路径】summarize_pipeline.py:
    ENV_FILE = /home/ubuntu/codex_graphrag/.ollmam_env
    （load_env_file 用 os.environ.setdefault 注入；文件缺失则跳过，不报错）
  【必需环境变量】
    ARK_API_KEY        — LLM 密钥（缺失则 call_llm 抛 RuntimeError）
  【可选环境变量】
    VOLC_BASE_URL      — 默认 https://ark.cn-beijing.volces.com/api/coding/v3
    MODEL_NAME         — 默认 doubao-seed-2.0-lite
    SUMMARIZE_PIPELINE_WORKERS — 并发线程数，默认 4
    SUMMARIZE_JSON_RETRIES     — JSON 重试次数，默认 2
    SUMMARIZE_MAX_OUTPUT_TOKENS— 重试时 max_tokens 上限，默认 8192
  【本地模型缓存】build_chunk_faiss.resolve_model_path():
    ~/.cache/huggingface/hub/models--sentence-transformers--all-MiniLM-L6-v2
    解析顺序：refs/main→snapshots/<rev> → snapshots 最新 → 目录本身；都不存在抛 FileNotFoundError
  【离线开关】build_chunk_faiss.main / query_chunk_faiss.main 强制:
    HF_HUB_OFFLINE=1、TRANSFORMERS_OFFLINE=1、TOKENIZERS_PARALLELISM=false（setdefault，不覆盖已设值）

数据契约（.env 行格式）：
  KEY=VALUE（# 注释、空行跳过；setdefault 不覆盖已存在环境变量）

状态 state：
  无；环境变量在进程内 setdefault，不写回文件

函数地图：
  - summarize_pipeline.load_env_file() → 读 ENV_FILE 注入 os.environ
  - build_chunk_faiss.resolve_model_path() → 定位模型快照
  - build_chunk_faiss.main / query_chunk_faiss.main → setdefault 离线变量

调用链/交互：
  启动 → load_env_file（summarize）/ setdefault 离线（build+query）→ 使用

关键逻辑：
  - 模型必须预先下载到 HF 缓存；离线变量确保不联网
  - setdefault 语义：环境变量已 export 则优先，.env 仅补缺

常见修改点：
  - 改密钥/模型/并发 → 改 ENV_FILE 内容或 export 环境变量
  - 换 embedding 模型 → resolve_model_path 的 MODEL_REPO_DIR（须与 DIMENSION=384 匹配）
  - 改离线策略 → 删除/调整 main 中的 setdefault（一般不动）

约束与坑：
  - ★ ENV_FILE 路径 /home/ubuntu/codex_graphrag/.ollmam_env 与 README 写的 /home/ubuntu/codex_english/.env **不一致**；照 README 配置不生效，必须落 .ollmam_env
  - ENV_FILE 文件名带疑似拼写 ".ollmam_env"（非 .env），属项目固有命名，勿擅自改
  - ARK_API_KEY 在 ENV_FILE 缺失时不会自动从系统读取（除非已 export）
  - 模型缓存目录缺失 → build/query 直接 FileNotFoundError（非友好提示）
  - 离线变量用 setdefault：若环境误设 HF_HUB_OFFLINE=0 会保留 0，导致尝试联网
  - 路径硬编码 /home/ubuntu/...：换机器/用户须改源码常量或建软链
