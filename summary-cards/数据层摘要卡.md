# 数据层摘要卡：CSV / FAISS / SQLite / graph_data.json

元信息：
  路径: results/（articles.csv, chunks.csv, chunks.faiss, chunks_meta.sqlite3）、web/graph_data.json
  类型: 文件型存储（CSV 文本 + FAISS 向量索引 + SQLite 元数据）
  入口: 由 summarize_pipeline / build_chunk_faiss / build_graph 写入，query_chunk_faiss 读取

结构（表/文件字段）：
  【results/articles.csv】ARTICLE_FIELDS:
    id, title, type, source, author, raw_content, summary, summary_json, word_count, status, created_at, updated_at
  【results/chunks.csv】CHUNK_FIELDS:
    id, article_id, chunk_index, content, summary, summary_json, token_count, embedding, created_at
    （注意：embedding 列恒为空，向量不在 CSV）
  【results/chunks.faiss】FAISS 索引:
    IndexIDMap2(IndexFlatIP(384))；维度 384；归一化内积=余弦；全量重建
  【results/chunks_meta.sqlite3】三表:
    - chunk_vectors(faiss_id INTEGER PK, id TEXT, article_id TEXT, chunk_index INTEGER)
        + 索引 idx on(article_id,chunk_index)、on(id)
    - chunk_texts(id TEXT PK, article_id, chunk_index, content, summary, summary_json, row_hash, created_at)
        + 索引 idx on(article_id,chunk_index)
    - build_info(key TEXT PK, value TEXT)  # built_at/model_path/dimension/row_count/metric/text_fields...
  【web/graph_data.json】{ meta, nodes[], edges[] }，字段见前端卡数据契约

数据契约（键关系）：
  - chunks.csv.id == chunk_texts.id == chunk_vectors.id（主键/外键纽带）
  - chunk_vectors.faiss_id ↔ FAISS 行号（index.search 返回的 indices）
  - article_id 关联 articles.csv 与 chunks.csv
  - summary_json（CSV 文本列）解析后驱动图谱节点/边

状态 state：
  无运行期状态；SQLite row_hash 用于行级去重判定

函数地图（读写点）：
  - summarize_pipeline.append_unique_rows() → 追加 articles.csv / chunks.csv（按 id 幂等）
  - build_chunk_faiss.read_chunk_records() → 读 chunks.csv（校验必需列、去重、skip 统计）
  - build_chunk_faiss.write_sqlite_metadata() → 写 SQLite 三表
  - build_chunk_faiss.replace_outputs_atomically() → 原子替换 .faiss + .sqlite3（备份回滚）
  - query_chunk_faiss.search() → 读 .faiss + join .sqlite3 返回 hits
  - build_graph.main() → 读 chunks.csv 写 web/graph_data.json

调用链/交互：
  summarize_pipeline → CSV → build_chunk_faiss → FAISS+SQLite；query 读 FAISS+SQLite join；build_graph 读 CSV 写 JSON

关键逻辑：
  - 全量重建：chunks.faiss / sqlite3 每次运行整体覆盖（非增量 upsert）
  - 行去重：同 id 内容一致忽略；内容不同忽略新行 + WARNING（旧行保留）
  - embedding 文本 = summary_json.human_summary + "\n" + core_argument；缺则整行跳过
  - FAISS 与 SQLite 通过临时文件 + rename 原子切换，失败回退备份

常见修改点：
  - 加字段 → 改对应 *_FIELDS 常量 + CSV 读写 + （如需检索）SQLite 建表 SQL
  - 改向量模型/维度 → build_chunk_faiss DIMENSION / MODEL_REPO_DIR（index 与 query 必须一致）
  - 改去重策略 → read_chunk_records 的 seen_hashes / duplicate_changed 分支
  - 改图谱数据粒度 → build_graph 输出；无需动 SQLite

约束与坑：
  - FAISS 维度硬编码 384，换模型（非 all-MiniLM-L6-v2）会维度不符 → query 抛 "FAISS 维度不是 384"
  - SQLite 表结构由 build_chunk_faiss 建，手动改表会破坏 rebuild
  - chunks.csv 缺列（id/article_id/chunk_index/content/summary/summary_json）直接抛 ValueError
  - graph_data.json 为前端快照，须 build_graph 后重新生成才会反映新数据
  - CSV 用 utf-8-sig 读写（兼容 Excel BOM）；csv.field_size_limit 已设为 maxsize
