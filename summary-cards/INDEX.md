# 摘要卡索引

- 前端卡 → 前端摘要卡.md | 改 web/index.html 配色/画布交互/详情面板/标签阈值/筛选时读
- 后端卡 → 后端摘要卡.md | 改切片/LLM摘要/构建FAISS/构建图谱/统计/清理脚本时读
- 数据卡 → 数据层摘要卡.md | 改 CSV/FAISS/SQLite/graph_data.json 字段与存储结构时读
- 外部服务卡 → 外部服务卡.md | 改 LLM 调用点/鉴权/模型/重试/超时时读
- 配置卡 → 配置摘要卡.md | 改 env 文件路径/环境变量/模型缓存路径/离线开关时读
- 部署卡 → 部署摘要卡.md | 改静态服务端口/启动命令/目录托管/CWD 要求时读

说明：本项目**无 API/路由层**（serve_graph.py 仅用标准库静态托管 web/，无路由/无业务接口），故不出路由卡。
所有处理脚本为批处理（CLI）形态，归入"后端卡"。
